In a world where you are being watched and monitored by AI, people begin buying handwriting fragments because they contain human irregularity. Imagine a device where people can insert writer's handwriting to write a message to someone. Humans have deliberately started using glitches as language in order to communicate and have come up with different visual symbols with hidden meanings. 
I wanted to make the interface look very medieval, since in this world, writing by hand has become a form of art that only people from the past or ‘ancient times’ used to do as a daily routine. It opens into a letter when you click the envelope and includes a brief introduction to the world we are supposed to be living in. The mail also includes instructions on how to use this artifact as a way to communicate with others. For transcribing whatever I say into a particular handwriting, I had to put my own handwriting as a sample. I added different manual controls to change the slope, curve, height, width of each letter, as well as add a controller for human errors. These human errors are like typos, that keep changing as you increase the error, eventually making the text look gibberish. There is also an option that lets you change the message back to original if you want to add more to it. To send a message through gestures, the sender has to hold that particular hand sign for atleast 3 seconds for it to get added in the letter. Along with this, I made a library in the corner where one can look up the meaning of each symbol that has been added to the letter.  There is a “send your message” button that converts the entire message along with the symbols into a letter format, to make it look as though this is the physical copy that you are actually sending.
